# Resource.io

A comprehensive contractor management platform built with Angular, designed to streamline the process of managing contractors, job profiles, and client relationships.

## Features

- **Job Profile Management**: Create, view, and manage job profiles
- **Contractor Management**:
  - Browse available contractors
  - View contractor details
  - Match contractors with job profiles
- **Client Dashboard**:
  - Overview of current projects
  - Contractor performance metrics
  - Payment management
- **Time Tracking**:
  - Timesheet management
  - Approval workflows
  - Weekly and daily views
- **Payment and Invoicing**:
  - Subscription management
  - Invoice generation
  - Payment processing
- **User Management**:
  - Multi-user type support (Clients, Contractors, Admins)
  - Profile management
  - Authentication and authorization

## Technical Stack

- Angular
- TypeScript
- Angular Material UI
- PWA Support (Service Workers)

## Getting Started

### Prerequisites

- Node.js (Latest LTS version)
- npm (comes with Node.js)
- Angular CLI

### Installation

1. Clone the repository:
```bash
git clone [repository-url]
cd Resource.io
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
ng serve
```

4. Navigate to `http://localhost:4200/` in your browser.

## Development

- Run `ng serve` for a dev server
- Run `ng build` to build the project
- Run `ng test` to execute unit tests
- Run `ng e2e` to execute end-to-end tests

## Project Structure

- `/src/app/` - Main application code
  - `/modules/` - Feature modules
  - `/shared/` - Shared components and services
  - `/assets/` - Static assets
